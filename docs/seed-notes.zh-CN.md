# 种子构建与静态 r2 实测记录

## 静态 r2 示例

`白绿拾遗-113` 的静态 r2 包在悲泣溪谷的原白光与原绿光各放一把武器。历史构建使用全随机、武器独立模式、单点刷怪、站桩与战斗对白，共改动 728 个资产。以下数据和实机记录均对应静态 r2。

| 模块 | 静态 r2 覆盖 |
| --- | --- |
| 奖励 | 1,137 个地图拾取、47 个宝箱、12 个任务、7 个 Boss 直发武器奖励、1 个普通怪物组结算。1,195 个奖励位置与原版不同。 |
| 物品池 | 支持全随机、武器、主武器、影之武装和收集品五种模式。全随机将七个 Boss 武器来源与普通奖励放在同一池，其中包括 383 个纯意识尘埃光点及 152 个文本光点。含文献和尘埃的组合整份转移。 |
| 光点颜色 | 地图光点使用最终物品的原版特效。武器复用牢门钥匙的橙红色，文献用绿色，纯意识尘埃沿用原数量档的白光。地图实例中的 Niagara 粒子与参数、缓存等级和掉落表等级一起更新。 |
| 武器数值 | 38 件武器支持同型互换物理伤害、失衡伤害、格挡失衡伤害倍率及归一化倍率。示例中 23 个来源 ID 改变。 |
| 武器连段 | 白影和偃月刀互换整套动作配置，保留各自模型引用和挂点。联动双开时采用数值和动作共同支持的武器；独立模式分别分配。 |
| 怪物 | 四张地图中 138 个普通刷怪点，另支持 52 个完整小组按相同规模换阵容。示例改变 119 个刷怪点的敌人类型。 |
| 对白 | 1,630 个站桩对白槽和 48 个可选战斗对白槽。一次替换对白行键，由游戏播放该行配对的音频、字幕。示例实际改变 1,079 个站桩对白键和 32 个战斗对白键。 |
| 通行能力 | 保留已识别的通行装备来源，将「三面混沌」所需的长形黑伤留在驿站。Boss 胜利独立解锁与 Boss 对手替换仍待实现。 [能力锁证据](../integrations/gates/README.md) |

当前目录只包含已核对的原版来源。通用规划器会对输入目录声明的依赖做可达性检查，真实游戏的完整流程依赖图仍未建立。完整通关、所有收集点和全部武器招式需要分别验收。

2026-11-18，安装 r2 后从 Steam 启动，进入标题画面 **302256-17280**。Windows Restart Manager 确认 PBZ 游戏进程实际打开了与发布包 SHA-256 一致的 `.utoc` 和 `.ucas`。

2026-11-19，玩家通过开场，并确认收集品出现在原版没有该收集品的位置。开端之地原奖励为 220 和 224 意识尘埃的两处光点均写入了已领取标记，背包分别增加了大师药师记忆 ×2 和兵刃逆炼符 ×1。重读存档后，两处标记和奖励均保留。其余三处已核对发布包内的分配。

同日的隔离实测在开端之地铃铛旁使用两个同类拾取实例，沿用发布种子的奖励和光效配置。两处均显示钥匙色的橙红光。拾取后，操偶铃铛和玉双环分别显示 3D 物品模型和装备提示。悲泣溪谷两个发行点位的实地表现及 Boss 发奖仍待验证。 [武器拾取实测](integration-research.md#地面武器拾取实测)

静态 r2 的种子包独立安装。同一安装中的所有槽位共用这套覆盖。r1 和 r2 的奖励目录不同，同名种子也会产生不同分配。

## 生成自己的种子

在仓库根目录构建含战役启动器、完整种子及离线切换配方的发行包。创建新种子需要 Windows、Python 3.10 或更高版本、cryptography、游戏本体和 Unreal Engine 5.7.4 的 UnrealPak 与 Oodle。构建启动器使用 Windows 的 .NET Framework 编译器。可加 --player-runtime 指向现有发行包的 Tools/Python；从零制作便携运行时使用 Windows x64 Conda Python 3.12、Tk 8.6 及对应的本地许可证。

```powershell
python -m pip install cryptography
python tools/prepare_tools.py
python -m pbzmod --config config.json --out build/my-seed
```

工具会验证下载件的 SHA-256，并自动定位 Steam 与 UE 5.7。可用 `--game "游戏根目录" --ue "UE_5.7目录"` 指定路径。选择一个尚未创建的输出目录。`catalog.json` 列出原始目录，`plan.json` 列出本次分配，`SHA256.json` 用于核对包内文件。

| 配置字段 | 取值 |
| --- | --- |
| `seed` | 非空字符串或整数。分享时一并提供本项目版本、游戏构建号和整个配置。 |
| `item_mode` | `all`、`weapons`、`main_weapons`、`shadow_weapons`、`collectibles` |
| `whitelist` | 可选的物品 ID 数组；省略时覆盖该目录可参与的武器和收集品。ID 可从生成的 `catalog.json` 查看。要仅剔除某把武器，可从 `plan.json` 的 `config.whitelist` 复制完整清单后删除该 ID，再保存为新配置。 |
| `weapon_mode` | `off`、`linked`、`independent`。启用后可用 `weapon_stats`、`weapon_movesets` 分别开关。 |
| `monster_mode` | `off`、`unit`、`group` |
| `ambient_voices`、`combat_voices` | 布尔值；分别控制站桩对话与战斗语音。 |

开发校验使用 `python -m unittest discover -s tests -v`。备用文件桥及其额外前置见 [Archipelago 接入说明](../integrations/archipelago/README.md)。预构建包使用原生资产路线。原版资源包、个人存档和构建工具二进制均独立于源码仓库。
