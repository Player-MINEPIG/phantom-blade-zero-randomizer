# 影之刃零随机周目

适用于 Windows x64 Steam build 26367565，标题版本 302256-17280。完整解压发行包，双击 `PBZRandomizer.exe`。从新建战役到中途切换，所需工具都在发行包里。

## 两个一周目档可以分别游玩

- **继续个人原版档**。从 Steam 正常启动。随机包保存在启动器旁边的 `Seeds` 目录，个人游戏使用原有存档路径。
- **新建随机档**。退出游戏，在启动器中创建战役，选种子并启动，再从游戏主菜单选「新游戏」。之后通过同名战役继续进度。每个战役只使用一个游戏槽位。
- **从已有原版档开始随机**。选「导入原版档库」，选取含有原版 `.sav` 的存档目录并给副本命名。它会以原版布局开始。导入会保留整套存档的目录层级。选定其中要继续的唯一槽位，核对它已领过的点，再启用随机。其他槽位可以各建一份独立战役。

若此前在 `ProjectPBZ/Content/Paks` 下安装过全局静态随机器，先把它的三个同名文件移出游戏搜索目录。使用这个发行包后，日常切换无需移动文件。

## 在同一份进度上启用或关闭

1. 用本战役的槽位存档并退出游戏。在启动器选择这个战役，点「切换此战役模式…」。
2. 对照刚保存的进度，勾齐已经领取的奖励点。可搜索点位和奖励；尘埃、已消耗材料、已读文献也算领取。若手头已有这个槽位当前周目的明文进度 JSON，可以导入以辅助勾选。缺失记录的点需要自己判断。
3. 确认清单完整，选择启用或关闭。窗口将在本机生成新布局，逐块回读成功后才切换战役。再次启动同名战役并继续原槽位。

导入的原版旧档首次启用时，点位有「已领」「仍可领」「保留原位」三种状态。只有明确仍可领取的点互相交换。未确认或永久错过的点保留原奖励，领取历史也不会凭空增加。可按地区或铃铛筛选，再批量确认仍能前往的光点与宝箱。

关闭时，武器数值与连段、刷怪及对白回到原版。未领取的奖励尽量回到原位。例如甲处原有尘埃，乙处原有武器。在甲处已提前拿走武器后关闭，乙处会留下尚欠的尘埃；其他可归位的奖励照原版发放。整个奖励一起移动，包括数量、文献附带的尘埃和对应的地面光效。

**切换结果取决于清单是否完整。** 零售版没有经过验证的自动读取入口。漏选已领点或误选未领点都会影响剩余分配。若无法确认，继续当前布局仍可游玩。回退到之前的检查点、换槽或进入下一周目时，须使用与该进度对应的战役和领取历史；为不同进度另存战役。

## 存放和备份

个人原档留在游戏的原存档位置。独立战役保存在 `%LOCALAPPDATA%\PBZSeedRandomizer\Campaigns\<战役名>`。备份或搬家时，一起保留该目录和发行目录中的 `Seeds`。修改后的布局和领取历史位于对应的布局目录。Steam 对个人原档的云同步不能替代独立战役备份。

## 实机验证

「白绿拾遗-113」在独立测试档中验证了玉双环和操偶铃铛的橙红光与拾取面板。测试把两件武器的发行配置放在开端之地铃铛旁的同类拾取点。发行包使用原点位，分别在斧老大关押处和溪谷杀气塔一层，两个点位的实地表现仍待验证。

随包的 `软件架构.html` 可以离线打开。游戏内原生开关、Boss 发奖和全流程通关仍待实机验证。
